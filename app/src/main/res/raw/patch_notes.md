## Command Panel v0.9.1

The Thor button works on more firmware, and the settings list scrolls back to the top.

### Fixes
- **Thor button opens the panel.** On some firmware, pressing the Thor button only darkened the bottom screen. It now opens the panel, and a press always brings a dark screen back.
- **Settings sections scroll back to the top.** Going up the section list in settings now reaches the very top again.

See the [v0.9.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.9.0) for the previous release.

> **About `tcp-sc-0.9.1.apk`:** an optional helper app, TCP SC. Apps like Back Button Hero can launch it to save a Replay Buffer clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
