## Command Panel v0.5.1

Replay Buffer fixes, plus a faster way to save a clip.

### New
- **Double-press AYN to clip.** Turn it on under Replay Buffer, then double-press the AYN button to save a clip. If the buffer is off, the first double press turns it on. Single presses wait a moment before opening the panel.

### Fixes
- **Bottom and Both screens now record.** Choosing which screen to capture used to keep recording the top screen until the buffer was turned off and on again.
- **Capture settings apply right away.** Changing the screen, clip length or quality restarts a running buffer with the new setting and tells you when it's done. Footage buffered before the change is cleared.

See the [v0.5.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.5.0) for the previous release.
