## Command Panel v0.8.1

The keyboard no longer hides behind the panel.

### Fixes
- **Keyboard stays visible.** When an app on the bottom screen shows the keyboard, it now appears over the panel instead of behind it.

See the [v0.8.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.8.0) for the previous release.

> **About `tcp-sc-0.8.1.apk`:** an optional helper app, TCP SC. Apps like Back Button Hero can launch it to save a Replay Buffer clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
