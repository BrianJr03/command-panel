## Command Panel v0.10.1

Choose where ThorKBM shows up in the panel.

### New
- **Keyboard switches.** Settings, Extras, Keyboard now has two switches: show or hide ThorKBM's button in the nav bar, and add or remove the Keyboard tile. The tile switch is the same one as in Tiles settings.

See the [v0.10.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.10.0) for the previous release.

> **About `tcp-sc-0.10.1.apk`:** an optional helper app, TCP SC. Apps like Back Button Hero can launch it to save a Replay Buffer clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
