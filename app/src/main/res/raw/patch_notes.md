## Command Panel v0.8.0

Save clips from Back Button Hero, and a home of its own for the Replay Buffer.

### New
- **Save clips from Back Button Hero.** Pick Launch app → TCP SC → bottom screen for a gesture or button combo. Each press saves a clip, or turns the buffer on if it's off, and your game keeps focus.
- **TCP SC install in one press.** The Replay Buffer section shows whether TCP SC is installed and installs the one that matches your version.
- **Replay Buffer section.** Every replay setting now has its own section, after Themes.
- **Move sections around.** Press A on a section in the list, move it with the D-pad and press A again, or drag its handle. Your order is saved and included in backups.

### Changes
- **Clip options in one card.** Double press, game audio and microphone sit together.
- **The tour** covers the new section, TCP SC and moving sections.

See the [v0.7.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.7.0) for the previous release.

> **About `tcp-sc-0.8.0.apk`:** an optional helper app, TCP SC. Apps like Back Button Hero can launch it to save a Replay Buffer clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
