## Command Panel v0.14.0

Media controls in the panel, colors you can share with Jarn, and a round of fixes.

### New
- **Media controls.** Turn on Media Controls in General to get previous, play/pause and next buttons in the middle of the panel's status bar. They control whatever is playing.
- **Share your colors with Jarn.** Jarn, the new Jarngreipr frontend, can match your Command Panel colors, from built-in looks and your own. Turn on Match Command Panel colors in Jarn's Look settings.

### Fixes
- **CPU gauge** shows your processor speed again instead of 0 on newer Thor firmware.
- **Bluetooth and Do Not Disturb tiles** turn off again, and light up whenever they're on.
- **Safer root features.** The root helper only takes commands from Command Panel, and an interrupted clip copy no longer leaves a broken file behind.

See the [v0.13.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.13.0) for the previous release.

> **About `tcp-sc-0.14.0.apk`:** an optional helper app, TCP SC. It's a shortcut for Replay Buffer: open it from a home screen shortcut, a gesture app or an app like Back Button Hero to save a clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
