## Command Panel v0.1.0

First packaged build of **Command Panel (TCP)** — a user-installable replacement for the AYN Thor's stock dual-screen assistant.

### Overlay
- Bottom-screen overlay with Mode and Settings tabs, hosted by a persistent foreground service and the AYN button.
- Screen modes: **Dual-screen**, **Only top screen**, **Only bottom screen** (both panels blanked with black covers).
- **Task** button opens system recents; **App** button launches the companion settings.
- Brightness + volume cards, 60/120 Hz toggle with live FPS pill, quick-setting tiles.
- Long-press **Arrange mode**: drag-and-drop to reorder overlay cards.
- Full gamepad navigation.

### Looks
- 16 selectable overlay looks, light + dark aware.

### Companion app
- Modern dark console UI, gamepad-navigable.
- Tile roster with drag-and-drop ordering.
- Ambient-LED → overlay accent sync.
- Settings backup & restore.

### Tools
- Replay Buffer tile (root screen-capture ring buffer → MP4 clip).
