## Command Panel v0.10.0

ThorKBM joins the panel as a keyboard add-on, settings get grouped, and turning a screen off now makes it truly black.

### New
- **ThorKBM keyboard add-on.** Get ThorKBM from Settings, Extras, Keyboard, with a preview and a link to its GitHub page. With a ThorKBM version that supports it, its keyboard slides into the panel's place on the bottom screen and the panel comes back when you close it.
- **Keyboard tile.** Add it in Tiles settings to open ThorKBM straight from the panel.
- **Grouped settings.** Sections now sit in Panel, Look, Extras and Advanced groups. Open or close a group with A or D-pad Right, and move a whole group with Y. The tour shows how.
- **New dots.** A small dot marks settings that changed in an update until you've looked at them.
- **Scrolling nav bar.** When the nav bar has more buttons than fit, swipe it sideways.

### Fixes
- **Screen off is fully black.** Holding the AYN button, and the only top screen and only bottom screen options, now black the screen out instead of dimming it. With the root helper, the status bar and every app are covered too.
- **Installs go straight to Android's installer.** Updates and add-ons no longer open an "Open with" list of other apps.
- **ThorKBM installs without root.** The card confirms when it's done.

See the [v0.9.1 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.9.1) for the previous release.

> **About `tcp-sc-0.10.0.apk`:** an optional helper app, TCP SC. Apps like Back Button Hero can launch it to save a Replay Buffer clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
