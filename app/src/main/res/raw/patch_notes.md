## Command Panel v0.15.0

Jarn can now use your look's fonts too.

### New
- **Share your fonts with Jarn.** Jarn can now use your current look's fonts as well as its colors, including fonts you imported. Only Jarn, signed by its developer, can open your imported font files.

See the [v0.14.0 notes](https://github.com/BrianJr03/command-panel/releases/tag/v0.14.0) for the previous release.

> **About `tcp-sc-0.15.0.apk`:** an optional helper app, TCP SC. It's a shortcut for Replay Buffer: open it from a home screen shortcut, a gesture app or an app like Back Button Hero to save a clip. You only need it for that, and Command Panel can install it for you from its Replay Buffer section. If you install it by hand, install it after Command Panel.
